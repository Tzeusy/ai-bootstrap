# Thesis retirement

The launcher and SQLite schema are disposable thesis instruments only. After
the run, delete the temporary database and remove or disable the launcher when
the evidence consumer no longer needs to reproduce the gate. Retain the
version-pinned synthetic fixtures, behavior tests, and this content-free
evidence record as test-only artifacts.

`thesis.retirement.assert_import_negative` scans every non-thesis production
Python source and package manifest in this project. It rejects a production
`thesis` import or thesis package declaration with a code-owned failure before
the thesis can become a production dependency. The test suite proves both
negative mutations while the actual project scan remains empty: no production
package, schema, runtime, sink, network, image, or publish target exists in
this change.

The immutable launch instrument's 15-minute sitting ceiling remains unchanged;
this capability's 10-minute/six-read-command bound is the stricter thesis
exercise and does not amend that instrument.
